## What changed

### MITRE ATLAS v2026.10 — 11 new techniques, 7 new/moved sub-techniques, 4 new mitigations, 4 new case studies

**Source:** [github.com/mitre-atlas/atlas-data/releases/tag/v2026.10](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.10),
published Oct 28, 2026. Confirmed directly against the release page (two independent fetches
agreeing): 16 tactics, **129 techniques, 92 sub-techniques (221 entries, up from 208 in
[v2026.09](https://github.com/mitre-atlas/atlas-data/releases/tag/v2026.09), Sep 15, 2026)**, 44
mitigations, 77 case studies, 44 entities, 37 software records. The release also ships ATLAS Data
Format v6.1.0 (first-class Entity and Software objects, new relationship types) and moves the
pinned ATT&CK Enterprise dataset for STIX export from v19.2 to v20.0.

**New techniques:** AML.T0135 Outputs from AI Models · AML.T0136 Exfiltration via AI User
Interface · AML.T0137 Training Data Information from AI Models (with four new/moved
sub-techniques: .000 Infer Membership, .001 Infer Properties, .002 Invert AI Model, .003 Extract
Memorized Data) · AML.T0138 Indicator Removal · AML.T0139 Compromise Accounts · AML.T0140
Centralized AI Service Request Routing · AML.T0141 AI Service Request Metadata Sanitization ·
AML.T0142 Event Triggered Execution · AML.T0143 LLM Prompt Propagation · AML.T0144 Recover AI
Model Internals · AML.T0145 Poison AI Agent Learning Environment. Plus sub-technique AML.T0017.003
Develop Capabilities: Malware, and two sub-techniques moved under Data from AI Services (.002
Conversation Context and Memory, .003 System Instructions, absorbing former AML.T0057/T0056
content).

**New mitigations:** AML.M0040 Adaptive AI Response Degradation · AML.M0041 Privacy-Preserving AI
Training and Inference · AML.M0042 Threat Intelligence Program · AML.M0043 AI Agent External
Resource Lifecycle Management.

**New case studies:** AML.CS0073–AML.CS0076 (names not retrieved this sweep — see Network note).

**Renames/moves** (checked against this ledger's existing citations — none affected): AI Supply
Chain Compromise → Supply Chain Compromise; Create AI Proxy Model → Replicate AI Model Behavior;
LLM Jacking → LLMjacking (AML.CS0030); AI Bill of Materials → Maintain an AI Bill of Materials;
AI Telemetry Logging → AI Telemetry Logging and Monitoring; the three AI Agent Tools Permissions
Configuration mitigations renamed to Manage Service/User-Delegated AI Agent Access and Enforce
Access Controls for AI Agent Tools; Infer Training Data Membership and Invert AI Model moved from
Exfiltration via AI Inference API into the new AML.T0137 above.

**Catalog mapping.** Most of this batch targets attacker-side infrastructure, account compromise,
or model-training/privacy extraction — the same declared-out-of-scope rationale this ledger has
applied to every prior ATLAS batch (a repo-local coding-agent guard cannot reach an adversary's
own operations against systems outside the repo it governs, or model-internals extraction): this
covers AML.T0017.003, AML.T0137 and its four sub-techniques, AML.T0139, AML.T0140, AML.T0141,
AML.T0144, and AML.T0145 (training-environment poisoning is training-time, not a coding agent's
runtime tool calls). **One technique gets a new coverage row:** **AML.T0135 "Outputs from AI
Models" + AML.T0136 "Exfiltration via AI User Interface"** sit in the same family as the already
`enforced (slice)` AML.T0086 Exfiltration via Tool Invocation row, but describe exfiltration
through the model/agent's own response content rather than a tool call or shell command —
`block-unapproved-egress` watches shell/network egress, not the agent's output channel itself, and
nothing in the catalog's registry inspects response text for exfiltrated data. Marked **`policy
wanted`** below rather than folded into T0086's existing slice, since no mechanism covers it.
**Three techniques are left unscored, not guessed at:** AML.T0138 Indicator Removal, AML.T0142
Event Triggered Execution, and AML.T0143 LLM Prompt Propagation are plausibly adjacent to existing
rows (T0101 Data Destruction via Tool Invocation; agent-trigger configuration under T0084; T0061
LLM Prompt Self-Replication, itself untracked in the coverage table) by name alone, but this
sweep could not reach their full technique pages (atlas.mitre.org DNS-blocked — see Network note)
to confirm the mechanism well enough to score honestly. Carried as open items for next week rather
than mapped on a name guess.
