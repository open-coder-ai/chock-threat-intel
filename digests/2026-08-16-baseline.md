# Baseline — 16 August 2026

The reference point every weekly digest diffs against. Compiled from the 22 published
AI/agentic threat frameworks current as of this date — OWASP GenAI (Agentic Top 10 2026,
Agentic Threats T1–T17 v1.1, LLM Top 10 2026, Data Security 2026, AI Exchange, AIVSS
v0.8), MITRE ATLAS v5.6.0 (incl. the AML.T0080–T0112 agentic expansion), NIST AI
100-2e2025, CISA guidance, CSA, Microsoft, Google SAIF, Unit 42, and the academic
aggregators.

Coverage tags refer to the [chock-catalog](https://github.com/open-coder-ai/chock-catalog)
at 32 policies (12 enforced / 20 advisory) and use its tiers: **enforced** means a gate
or guard blocks a deterministic slice; **advisory** means rule text an agent reads;
**`policy wanted`** means nothing covers it yet.

## Open `policy wanted` items

1. **[`verify-mcp-allowlist`](https://github.com/open-coder-ai/chock-catalog/issues/1)** — ASI04 / ATLAS AML.T0110 (tool poisoning), T0109 (rug
   pulls): allowlist gate over MCP server entries in committed client configs, the
   `verify-dependency-exists` mechanism applied to `.mcp.json`. Deterministic; good
   first policy.
2. **[`block-unapproved-egress`](https://github.com/open-coder-ai/chock-catalog/issues/2)** — ATLAS AML.T0086 (exfiltration via tool invocation);
   the third leg of the "lethal trifecta" (private data + untrusted content + external
   comms): pre-tool-use guard refusing data-carrying egress commands to hosts outside a
   visible allowlist.
3. **T4 resource overload / unbounded consumption** (OWASP LLM06): needs the framework's
   planned cost circuit-breakers; not expressible as a diff or command gate today.
4. **T8 repudiation** as a policy: narrate the existing gate event log as an auditable
   claim rather than an undocumented mechanism.
